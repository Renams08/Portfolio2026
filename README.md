# 🚀 Portfolio 2026

Bienvenue sur le code source de mon portfolio ! Ce projet a pour but de présenter mes compétences en développement web, en design d'interfaces et de regrouper mes réalisations les plus récentes.

## 📝 À propos

Ce portfolio est une vitrine interactive de mon travail. Il me permet de centraliser mes projets professionnels et personnels, et de démontrer mon savoir-faire technique et créatif à de potentiels collaborateurs ou clients.

## 🛠️ Technologies & Outils

Ce projet a été construit avec les technologies suivantes :

*   **HTML5** (33.4%) - Pour la structure et la sémantique.
*   **CSS3** (49.9%) - Pour la mise en page, le design et les animations.
*   **JavaScript** (16.7%) - Pour l'interactivité et la dynamique de la page.

## 🌟 Exemples de Projets

Voici un aperçu du type de projets que vous pourrez retrouver sur ce portfolio :

*   **Maquettes d'Interfaces Universitaires :** Synthèse de documents de création et conception UI/UX pour le site internet d'une université.
*   **Créations Graphiques Personnalisées :** Design de templates et de contrats visuels intégrant des personnages de jeux vidéo ou des chartes graphiques spécifiques pour divers clients (comme le projet pour les comptes Panda et EllenDoeWhite).
